Conversation tag catalog

Clients can discover tags without downloading conversation rows and use the same exact-match filters for search and count.

SurfaceBeforeAfter
GET /api/conversations/search and /count Status filterOptional repeated tags__contains=key=value, with AND semantics and HTTP 400 for malformed items
GET /api/conversations/tagsClients paged through search An array of distinct {key, value, count} entries
TypeScript clientSearch sent an ignored tag option Search and count send tags__contains. listConversationTags() reads the list.

How the catalog stays current

PATCH already refreshes the catalog after saving. Tag enumeration uses that record directly, and search applies the filter before pagination.
