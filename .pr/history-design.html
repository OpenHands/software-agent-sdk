Recover original conversation history

A standalone retrieval tool lets an agent search and page through original events that no longer fit in its model input. It works independently of the reset policy and leaves existing condensation behavior intact.

Source baseline 8ba966d1d3af → head 7ba20ec00b5d. Source links are pinned; commits must be published before remote links resolve.

★ Add one optional conversation_history tool. It can recover message/tool text that condensation removed from the active model input, using the current conversation’s existing event history. openhands-sdk/openhands/sdk/tool/builtins/conversation_history.py:207

ADDED conversation_history.py

history_event_text exposes ordinary user/assistant message text, tool arguments, and tool results. It excludes internal/system events, provider reasoning fields, and this tool’s own calls/results. This is a projection boundary, not a semantic or secret-detection index. openhands-sdk/openhands/sdk/tool/builtins/conversation_history.py:85

Reads are restricted to active_branch(): inherited fork events remain available, while sibling/abandoned branches are unavailable. Cross-process retrieval depends on normal conversation persistence. Sync and async execution capture one snapshot before tool workers start. The direct executor path captures its own snapshot under the existing state lock.
