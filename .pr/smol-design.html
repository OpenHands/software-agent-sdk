One ephemeral local VM per workspace

SmolWorkspace adds an optional execution provider to openhands-workspace. It starts the existing Agent Server in a local microVM and inherits the remote command, file, Git and conversation clients.

Release gate: a published Smol wheel must include atomic loopback publication and pass the OpenHands image and conversation tests. Current validation is recorded in smol-validation.md.

Guest tools + private guest filesystem

A private helper process owns the native Smol handle. Constructor settings travel through stdin; native output is discarded. The parent enforces startup and shutdown budgets, checks health and authenticated execution, and initializes the inherited remote client. The helper deletes the exact owned VM on close or failed creation. If native code blocks, the parent terminates the helper and attempts exact-identifier cleanup within the remaining budget.

Compatibility and credentials

The export and dependency are optional and lazy. Existing providers and Agent Server are unchanged. Serialized construction settings contain the workspace discriminator and start a fresh VM when reconstructed. Environment values, runtime handles, endpoint and generated authentication are excluded from dumps and repr. Host mounts, attach, cloud, persistence and pause/resume are outside this interface.

Prerequisite contribution

The Smol engine binds a loopback TCP listener on port zero and registers that same listener with its shared acceptor. Its local control socket returns the actual port, which is persisted under the machine lock. The Python SDK exposes this as Machine.publish_atomic and an async counterpart. This avoids a free-port probe followed by a separate bind.

Verification

Default provider tests use a fake Smol SDK. Opt-in tests exercise real image startup, isolation, authentication, commands, file round trips, Git, cleanup and a deterministic conversation fixture in guest loopback. Published-wheel, image-digest and host-architecture evidence is required for each advertised platform.
