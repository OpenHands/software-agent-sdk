Capacity rescue is a fallback, not autonomous success

With known effective capacity, the model receives one reminder at 80% to below 100% of estimated input capacity. The reminder re-arms after a real view change. At/above capacity, the harness attempts recovery before the next main request. With unknown capacity, there is no fabricated threshold; a provider context-window failure can still trigger recovery. openhands-sdk/openhands/sdk/context/condenser/agent_reset_condenser.py:32 openhands-sdk/openhands/sdk/agent/agent.py:774

The emergency path reuses LLMSummarizingCondenser.hard_context_reset on eligible history with the agent LLM, preserves user/system input, and rejects a result that does not reduce input or still exceeds known capacity. A model-reset candidate whose protected handoff/batch cannot fit fails before committing it. openhands-sdk/openhands/sdk/context/condenser/agent_reset_condenser.py:173 openhands-sdk/openhands/sdk/agent/agent.py:804

One outer rescue per main-step recovery attempt does not mean one LLM request. The reused summarizer has a finite internal retry loop (default 5 attempts), and normal provider retry behavior still applies. Exhaustion/failure must surface; it must not be counted as the model choosing a timely reset. openhands-sdk/openhands/sdk/agent/agent.py:791 openhands-sdk/openhands/sdk/context/condenser/llm_summarizing_condenser.py:81 openhands-sdk/openhands/sdk/context/condenser/llm_summarizing_condenser.py:375

Adopt the simpler model-managed direction

This revision follows the direction discussed with enyst: independent history retrieval, model-requested resets, and optional ordinary-file notes. It replaces the unpublished context_notes/notes-retrieval/storage proposal; it does not remove a released API or add preview-format migration obligations. openhands-sdk/openhands/sdk/tool/builtins/new_context.py:63 openhands-sdk/openhands/sdk/settings/model.py:343

Retained capabilities are original-history search/read, a handoff into the next view, optional file-based notes, replay/reopen/fork, and capacity recovery. The narrower surface omits a special notes schema, history index, custom storage layer, and a menu of reset heuristics. The file editor example writes an approval note, resets, reads the file, and retrieves an omitted historical value. examples/01_standalone_sdk/agent_reset/main.py:31

PR A can stand alone with ordinary summarization. PR B depends on A and changes only the opted-in reset policy. There is no claim that this reproduces another implementation or demonstrates a benchmark improvement.
