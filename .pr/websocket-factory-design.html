Custom Remote Event Transports

Issue #4708; prior work #4135 by p1c2u, closed for inactivity. This implementation addresses the recorded return-type and public-entry-point findings on current main.

Problem and Boundary

A remote conversation constructs the concrete WebSocket callback client internally. A controller using a Unix socket cannot select its own event transport without replacing module globals. The factory belongs to the Python client, not to the server request or persisted settings.

BeforeAfter
Conversation(..., websocket_client_factory=...) raises TypeError.The public factory forwards the optional transport factory to the remote conversation. Local workspaces reject a supplied factory explicitly.
The earlier proposal returned the concrete WebSocketCallbackClient.WebSocketClientFactory returns a structural WebSocketClient. A transport exposes a writable callback attribute and implements start, stop, and wait_until_ready.
Default transport is selected at connection initialization.This remains late-bound when the factory is None; existing default-client patching continues to work.

Public Construction Paths

Conversation(..., workspace=remote_workspace, websocket_client_factory=factory)
RemoteConversation(..., websocket_client_factory=factory)
RemoteConversation.create(workspace, request, websocket_client_factory=factory)
RemoteConversation.attach(workspace, id, websocket_client_factory=factory)

fork() retains the parent's factory but constructs a new client for the child. Each client has its own lifecycle. A new controller must provide its factory again when attaching.

Ownership and Compatibility

The factory returns an unstarted client. The SDK owns startup, subscription readiness, initial reconciliation, failure cleanup, and shutdown after handoff. The transport owns authentication, decoding, reconnection, and its background workers; it invokes the supplied reconciliation callback after resubscribing and before forwarding replacement-connection events.

No REST or WebSocket wire schema, persisted model, dependency, package version, or default transport implementation changes. HTTP continues through the workspace client. The repository's public API comparison against the base reports zero breakages.
