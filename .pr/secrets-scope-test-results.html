What the feature does

  • Adds scope and scope_description to SecretSource (inherited by StaticSecret / LookupSecret).
  • When any secret has a scope, <CUSTOM_SECRETS> groups secrets by scope with the description as a heading.
  • When no secret has a scope, output is byte-identical to the legacy flat list — prompt caching unaffected.
