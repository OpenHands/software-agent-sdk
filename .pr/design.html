Count the charge the provider already reported.

A custom alias can return usage.cost = 0.04 and still leave accumulated SDK cost at zero. This patch adds the missing reported-usage fallback while preserving authoritative headers and explicit token pricing.

★ Same HTTP input: $0.00 before → $0.04 after. A valid zero header still wins. This does not establish the customer's gateway forwarding or hidden router charges.

Reviewer decision: a zero header remains authoritative

This preserves the existing contract. A gateway that sends zero as an unknown estimate needs a separate agreed precedence rule. Hidden router-selection calls, upstream user attribution, two-proxy rewriting and Enterprise UI formatting remain outside the proven SDK fix.
