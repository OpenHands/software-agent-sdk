Public MCP OAuth redirect for the agent-server

Fixes OpenHands#18888 and the agent-server half of OpenHands#15430. Install-time MCP OAuth (POST /api/mcp/oauth/start) always registered http://localhost:<random port>/callback as the redirect URI. That port lives on the agent-server host, so the browser can only reach it when the browser and the agent-server share one machine and one network namespace.

Before / after

Before 
browser ── authorize ──▶ provider
provider ── 302 ──▶ http://localhost:47071/callback
                    (browser's own localhost:
                     ERR_CONNECTION_REFUSED)
probe waits 5 min ─▶ "Sign-in was not completed"
After (public URL known) 
browser ── authorize ──▶ provider
provider ── 302 ──▶ https://canvas.example/api/mcp/oauth/redirect
agent-server: find job by OAuth state, hand code to probe
probe exchanges code ─▶ "Connected — N tool(s)"

Which redirect URI is used

OAuth clientweb_url / OH_WEB_URL setonly callback_base_url in the requestneither
dynamically registered (DCR){web_url}/api/mcp/oauth/redirect{callback_base_url}/api/mcp/oauth/redirectloopback (unchanged)
pre-registered (client_id or metadata URL){web_url}/api/mcp/oauth/redirectloopback (unchanged)loopback (unchanged)

A pre-registered client's redirect URIs are fixed at the provider, so a browser-supplied base must not change them; only the operator's web_url does. A DCR client stored from an earlier loopback registration is dropped and registered again when its redirect URIs do not contain the new URI.

API

POST /api/mcp/oauth/start          body: MCPTestRequest + callback_base_url?: string  (plain http(s) base, no query/fragment/userinfo)
GET  /api/mcp/oauth/redirect       new, unauthenticated, not in OpenAPI; ?code&state[&iss] or ?error[&error_description]

The redirect route is outside the session-key dependency because the provider sends the user's browser there. It accepts a request only for a registered, unexpired job that is currently waiting for a redirect and whose OAuth state matches (constant-time compare). The first redirect wins; a replay gets 409; a provider error fails the probe with the provider's description.

Compatibility

  • No public URL configured and none sent: behavior is identical to before (loopback callback server, existing /api/mcp/oauth/callback/{job} relay).
  • callback_base_url is optional; older clients keep working.
  • Agent Canvas sends callback_base_url = its backend origin (companion OpenHands PR).
